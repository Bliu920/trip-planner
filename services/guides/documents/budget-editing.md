# Update a budget

Read budget-research for price and source rules. Read trip-details when interpreting changed budget, group or date requirements and update the Travel brief where applicable. Read the current budget before editing. Preserve unrelated entries, user limits, existing evidence, quantities and stable IDs. A manual user adjustment is not authorization to fabricate a supporting quote. If no substantiating source exists, mark the price unknown and record the user's request in its assumptions until verified.

Reconcile costs affected by changed plan item IDs, nights, traveler count, dates, location or selected activities. Remove obsolete item links only after understanding whether the cost itself should remain, such as a non-refundable booking. Removing a plan item does not cancel a booking. Newly added paid arrangements need researched prices or comparable-based estimates under budget-research; unknown is only an exceptional evidence failure. Do not treat a partial list of researched prices as a complete trip total.

Do not silently change scope or traveler count and leave quantities unchanged. Recalculate affected quantities, shared costs and evidence applicability together. Do not silently reinterpret the user's spending limit when changing from party to per-person scope. Keep old evidence timestamps for reused sources. Refresh through actual research if applicable prices may have changed.

Use editBudget for targeted changes to an existing estimate, preserving unrelated entries and evidence. Use createBudget only when absent. replaceBudget is available inside editBudget for a deliberate whole replacement. recordReview acknowledges that the whole budget was checked against the current/staged itinerary, not that all prices are confirmed. A full review should fill ordinary missing prices with researched estimates. Exceptional unknowns must be reported as an incomplete budget, even when reviewed true. Omit recordReview for a partial edit without that check. Commit all related changes atomically. On conflict reload and reconcile with the latest budget; never overwrite it using a stale snapshot. The same budget feeds both the Plan card and Budget tab, so do not maintain another total in Plan or Markdown.

Read budgetCheck after staging. Missing costs return the budget-gaps guide automatically. Fill prices or resolve remaining gaps before commit. For a limit-only or other partial edit, unchanged unknown entries can be preserved with reviewed false when the Plan and estimate scope are unchanged. This preserves uncertainty without claiming a fresh research review. A full review or changed cost must handle its missing-price feedback.
